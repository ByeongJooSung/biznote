안드로이드 앱 내려받기

안드로이드 8.0 이상 · 무료

아이폰용은 아직 준비 중이에요. 안드로이드 휴대폰에서 열어 주세요.

설치 방법

  1. 위 버튼을 눌러 파일을 내려받아요.
  2. 다운로드가 끝나면 알림이나 ‘내 파일 → 다운로드’에서 biznote.apk를 눌러요.
  3. ‘출처를 알 수 없는 앱’ 안내가 나오면 설정 → 이 출처 허용을 켜고 돌아와 설치를 눌러요.
  4. 설치 후 앱을 열고, 상대와 휴대폰을 다시 맞대면 명함이 들어와요.

플레이스토어 정식 출시 전이라 직접 설치 방식이에요. 출시되면 이 페이지에서 바로 스토어로 안내해 드려요.

이런 걸 할 수 있어요

  • 명함 촬영 → 이름·회사·연락처 자동 정리
  • 휴대폰을 맞대거나 부딪혀서 명함 교환
  • 회사 사람 전화가 오면 회사·직급 표시
  • 휴대폰 연락처와 따로 보관해 개인정보 보호
